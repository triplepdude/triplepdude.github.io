At 16 pixels detail disappears: one or two bold letters or a simple mark read better than a full logo, as the enlarged 16 px preview shows. ## SVG, dark mode and emoji An SVG favicon stays sharp at any size and can carry a dark style, a second set of colours for browsers in dark mode. Chrome and Firefox switch to it; Safari keeps the light colours (reported on Safari 26.3 as WebKit bug 309949, still open), so the dark tab preview shows both. An SVG logo that has a dark style of its own keeps it in icon.svg, while the PNG and ICO files take its light colours. Letters become outlines, so icon.svg needs no font, except for characters outside the fonts' Latin set and accents typed as separate marks, which then use each visitor's own font. An emoji favicon keeps the emoji as text in icon.svg, so every device draws its own version, while the PNGs copy your device's artwork. That artwork belongs to the font's maker: Apple's and Samsung's emoji are proprietary, Google's Noto Color Emoji is under the SIL Open Font License and Microsoft's Fluent Emoji are MIT-licensed. ## Phones and maskable icons iPhones and iPads use apple-touch-icon.png before the manifest's icons and show a transparent one on black, so that file is always filled. Chrome's install prompt asks for a 192 and a 512 px icon in the manifest. Android crops icons to circles and other shapes; a maskable icon keeps its content inside the safe zone, the central circle 80% as wide as the icon, on a background that runs to the edges. ## When the old icon keeps showing Browsers keep favicons in a cache of their own. In Chrome, a reload that skips the cache (Ctrl+Shift+R, or Cmd+Shift+R on a Mac) fetches it again. Giving the file a new name, or adding `?v=2` to its links, makes every browser fetch the new one, but Google asks for a stable favicon address, so change it rarely. Make the icon from
1 to 3 characters: an initial, a short name or a number.

Pick an emoji
On a phone, use the emoji keyboard. On Windows press Win + . (full stop); on a Mac, Ctrl + Cmd + Space.

Your device’s emoji font draws the emoji. icon.svg keeps it as text, so other devices show their own version of it, while the PNG and ICO files copy the artwork you see here.

Background

The iPhone and maskable Android icons cannot be transparent, so they get this colour behind the icon.

Browsers in dark mode use these colours from icon.svg; the PNG and ICO files keep the light ones.

Your icon. The checks show transparent areas.

Real-size previews

Drawn at the size browsers and phones show them, at your screen’s resolution.

Your files

Shown under the icon on phones, which cut it at about 12 characters.

Where your site and these files are: / for a site at the root of its domain, or a folder such as /blog/ for a site in a subfolder.

  • favicon.ico

    16, 32 and 48 px in one file, for every browser and for the /favicon.ico they request when a page declares no icon.

  • icon.svg

    Sharp at any size in Chrome, Edge, Firefox and Safari 26, and the only file that can switch to a dark style.

  • favicon-96x96.png

    For Google Search, which does not take SVG and recommends an icon larger than 48 px.

  • apple-touch-icon.png

    180 px for iPhone and iPad home screens, filled to the edges: iOS would put a transparent icon on black and rounds the corners itself.

  • icon-192.png

    Android home screens; Chrome’s install prompt asks for this size in the manifest.

  • icon-512.png

    Install dialogs and splash screens of installed web apps; Chrome asks for a 512 px icon too.

  • icon-maskable-512.png

    For Android launchers that cut icons to a circle or another shape: the icon stays inside the central 80% circle, on a background that runs to the edges.

  • site.webmanifest

    The site’s name, colour and icons, for Android home screens and installed web apps.
