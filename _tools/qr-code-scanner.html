Wi-Fi, contacts and more are read in your browser. category: Image & PDF keywords: [qr code scanner, scan qr code, qr code reader, qr scanner, scan qr code from image, qr code scanner online, scan qr code from screenshot, scan qr code on laptop, scan qr code from photo, read qr code, qr code decoder, barcode scanner, barcode reader] howto: | ## How to scan a QR code online 1. Press **Start camera** and allow camera access when the browser asks. Phones use the back camera. Hold the code inside the frame until it is read; the camera then turns off. Tick **Keep scanning** to read one code after another. 2. Or scan a picture: press **Choose image**, drop an image on the box, or paste a screenshot with **Ctrl+V** (**⌘V** on a Mac). PNG, JPEG, WebP, GIF, HEIC and other formats work, and up to eight codes in one picture are read. 3. Read the result. Nothing opens by itself: a link shows the website it leads to first, and only **Open** takes you there. For a code on your own screen, take a screenshot and paste it here: **Win+Shift+S** on Windows and **Ctrl+Shift+⌘+4** on a Mac copy the area you select. On a phone, pick the screenshot with **Choose image**. To copy printed text from a photo or screenshot rather than a code, use [image to text](/image-to-text/). ## What the result shows | The code starts with | Shown as | What you can do | |---|---|---| | `https://` | Web link and its domain | Open or copy it | | `WIFI:` | Wi-Fi network | Copy the password | | `BEGIN:VCARD`, `MECARD:` | Contact | Save it as a .vcf file | | `BEGIN:VEVENT` | Calendar event | Save it as an .ics file | | `mailto:`, `tel:`, `SMSTO:`, `geo:` | Email, call, text, place | Open the matching app | | `otpauth://` | Two-step sign-in key | See the account; the key stays hidden | | `upi://`, `BCD`, `000201` | Payment | Check payee, amount and checksum | SEPA codes (`BCD`) have their IBAN checked, and EMV merchant codes such as Pix have their CRC checked, so a mistyped or altered code is flagged. Text is read as UTF-8 or in the character set the code declares. Every scan is listed under **History** while the page stays open. ## Is it safe to scan a QR code? Reading a code is harmless; the risk is where a link leads. In January 2022 the FBI warned that criminals replace real codes with their own, for example with a sticker, and in December 2023 the US Federal Trade Commission reported fake codes on parking meters and in texts and emails. Before you press **Open**, check the domain. The page warns when a link: - starts with `http://`, so it is not encrypted; - is a short link (bit.ly, tinyurl.com and others), which hides where it goes; - has a name before an `@`, as in `paypal.com@203.0.113.9`, where only the part after the `@` is the real site; - uses an IP number, an unusual port or letters beyond a to z, such as a Cyrillic а in `аpple.com`; - downloads an app or program (.apk, .exe and others). Never type a password or card number on a page a code opened unless you are sure it is the real site. To make your own codes, use the [QR code generator](/qr-code-generator/) or the [Wi-Fi QR code generator](/wifi-qr-code-generator/). ## If the camera does not start - Allow the camera: click the icon at the left of the address bar. In Safari on iPhone, open Website Settings from the page menu in the address bar and set Camera to Allow. - On iPhone and iPad the camera works in Safari, and in Chrome and Firefox since iOS 14.3. Pages opened inside a social media or chat app often cannot use it; open the page in your browser. - Close other apps that use the camera, then press Start camera again. The [webcam test](/webcam-test/) shows what the browser reports. ## Barcodes Chrome on Android, macOS and ChromeOS has a built-in barcode reader. There the page also reads the codes it supports, such as EAN, UPC, Code 128, Data Matrix, PDF417 and Aztec, and checks the check digit of product numbers. Elsewhere, including Chrome on Windows and Linux, Firefox and Safari, it reads QR codes only, with the jsQR library. The note below the box says which applies to your browser. faq: - q: Is my camera picture or image uploaded? a: No. Camera frames and images are read by JavaScript in your browser, and nothing is sent to a server or stored. The history exists only in this tab and is gone when you close or reload it. - q: Do I need an app to scan a QR code? a: No. The Camera app on iPhone (since iOS 11) and on most Android phones reads QR codes, and so does Google Lens. This page helps on a computer, for screenshots and photos you already have, and when you want to see a link's domain before anything opens. - q: Why won't my QR code scan? a: Glare, dim light and holding the phone too close are the usual causes; move back until the whole code is sharp. The code also needs its white border and enough contrast. For a photo or screenshot, a sharper or closer picture of the code helps more than a bigger file. - q: Can this page connect me to a Wi-Fi network? a: No, a web page cannot join a network for you. It shows the network name and password so you can copy them. To join in one step, scan the code with your phone's Camera app, which offers to connect. ---
