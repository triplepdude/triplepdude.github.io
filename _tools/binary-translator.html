Runs in your browser. category: Developer keywords: [binary translator, binary to text, text to binary, binary code translator, binary converter, binary to decimal, decimal to binary, binary to hex, ascii table binary] howto: | ## How to translate binary to text Choose **Binary to text** and paste the code. The translator reads the 0s and 1s in groups of eight (one byte), turns each byte into a number and looks up the character with that number. Spaces, line breaks and punctuation between the groups are ignored, a `0b` prefix is skipped, and a group shorter than eight digits is filled with leading zeros, so `1001111 1001011` works too. For example, `01001111 01001011` is two bytes. 01001111 is 64 + 8 + 4 + 2 + 1 = 79, the code of **O**, and 01001011 is 75, the code of **K**: the message is "OK". For the other direction choose **Text to binary** and type. Every character is written as its UTF-8 bytes, eight digits per byte, with or without a space between the bytes. **Swap** turns the result into the input. The table under the result lists each character with its Unicode code point and its bytes in binary, hex and decimal. ## Is every character 8 bits? No. Only the 128 characters of ASCII fit in one byte. UTF-8, the encoding of almost every web page, keeps those 128 bytes as they are and writes every other character as two, three or four bytes: | Code points | Bytes | Bit pattern | |---|---|---| | U+0000 to U+007F | 1 | 0xxxxxxx | | U+0080 to U+07FF | 2 | 110xxxxx 10xxxxxx | | U+0800 to U+FFFF | 3 | 1110xxxx 10xxxxxx 10xxxxxx | | U+10000 to U+10FFFF | 4 | 11110xxx 10xxxxxx 10xxxxxx 10xxxxxx | So **é** is `11000011 10101001`, **€** takes three bytes and most emoji take four. Capital and small letters differ in a single bit: A is 01000001 and a is 01100001. Some tools write one number per character instead of UTF-8 bytes, such as 11101001 for é or 10000111111 for the Cyrillic п. When the groups are not valid UTF-8, the translator reads each group as a Unicode code point, and the line under the result says how the input was read. ## How to convert binary to decimal by hand Each binary digit is worth twice the one on its right: 1, 2, 4, 8, 16, 32, 64, 128, counted from the right. Add the values of the places that hold a 1: `1101000` = 64 + 32 + 8 = **104** From decimal to binary, divide by 2 until you reach 0 and read the remainders from the last to the first: 104 → 52 r 0, 26 r 0, 13 r 0, 6 r 1, 3 r 0, 1 r 1, 0 r 1, which reads 1101000. ## Binary to hex and octal One hex digit stands for four binary digits and one octal digit for three. Group the digits from the right: `110 1000` is hex **68**, and `1 101 000` is octal **150**. | Decimal | Binary | Hex | Octal | |---|---|---|---| | 10 | 1010 | A | 12 | | 104 | 1101000 | 68 | 150 | | 255 | 11111111 | FF | 377 | | 65,535 | 1111111111111111 | FFFF | 177777 | The number converter works with exact whole numbers of any length, so values above 2^53 (9,007,199,254,740,992), where ordinary JavaScript numbers start to lose digits, stay correct. A negative number gets a minus sign, and the note under the boxes adds its two's complement form. Related tools: the [chmod calculator](/chmod-calculator/) for file permissions in octal, the [hash generator](/hash-generator/) for checksums in hex, the [HEX to RGB converter](/hex-to-rgb/) for colour codes, [number to words](/number-to-words/) for writing numbers out, and the [Morse code translator](/morse-code-translator/) for dots and dashes. faq: - q: What does 01101000 01101001 mean? a: It says "hi". 01101000 is 104 in decimal, the ASCII code of a small h, and 01101001 is 105, the code of a small i. Paste any other binary message into the translator to read it the same way. - q: Why does my binary have a leading 0? a: ASCII is a 7-bit code, but computers store text in 8-bit bytes, so the first digit of every ASCII character is 0. In UTF-8 that leading 0 also marks a character that fits in a single byte. Leave the zeros in, because they keep every group eight digits long. - q: How do I write my name in binary? a: Choose Text to binary and type it. Every letter from A to Z becomes eight digits, capitals starting with 010 and small letters with 011, so Sam is 01010011 01100001 01101101. An accented letter takes 16 digits in UTF-8, so the ë of Zoë is 11000011 10101011. - q: Does binary code need spaces between the groups? a: No. Without spaces the digits are read eight at a time, so their number must be a multiple of 8. Spaces are only needed when groups are shorter or longer than eight digits. - q: Is my text sent to a server? a: No. The translation is done by JavaScript in your browser. Nothing you type or paste is uploaded or stored, and the page keeps working offline once it has loaded. ---
