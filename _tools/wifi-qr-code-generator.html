Download PNG or SVG, or print a card. category: Generators keywords: [wifi qr code generator, wifi qr code, qr code for wifi password, share wifi password, wifi password qr code, guest wifi qr code card, printable wifi qr code] howto: | ## How to make a Wi-Fi QR code 1. Type the **network name** (SSID) exactly as your phone lists it. Capitals, spaces and punctuation all matter. 2. Type the **password** and pick the **security** type. Almost every home and office router uses WPA2 or WPA3, so leave it on WPA/WPA2/WPA3 unless your router settings say WEP or the network has no password. 3. Tick **Hidden network** only if the network does not appear in your phone's Wi-Fi list. 4. Scan the preview with your phone before you download or print it. The Camera app on iPhone and on most Android phones offers to join the network when it sees the code. ## What is inside the code The QR code holds a short line of text in the format first published by the ZXing barcode project, which phone cameras recognise: `WIFI:T:WPA;S:Home Network;P:secret pass;;`. The box under the preview shows the exact text for your network. | Field | Meaning | Values | |---|---|---| | `T:` | Security type | `WPA` (covers WPA, WPA2 and WPA3 Personal), `WEP`, or `nopass` | | `S:` | Network name | Up to 32 bytes; most accented letters take 2, an emoji 4 | | `P:` | Password | Left out for open networks | | `H:` | Hidden network | `true` when the network does not broadcast its name | Because `;` ends a field and `:` separates a field's name from its value, the characters `\`, `;`, `,`, `:` and `"` inside a name or password are escaped with a backslash. A password of `pa;ss` is written `pa\;ss`. The generator does this for you, and the scanner removes the backslashes again. Text is encoded as UTF-8, so names with accents or emoji work. One oddity from the ZXing format: its original Android scanner app read a network name made only of hex digits (such as `CAFE1234`) as hex-encoded bytes, and the format suggests wrapping such a name in double quotes. The **Quote a hex-only network name** option does that. Leave it off unless a scanner gets the name wrong. ## Error correction and size QR codes store extra recovery data, so a code still scans when part of it is scratched, dirty or covered. | Level | Can recover about | Good for | |---|---|---| | L | 7% of the code | Clean screens, smallest pattern | | M | 15% | Most uses (default) | | Q | 25% | Printed cards that get handled | | H | 30% | Outdoor signs, laminated or worn prints | Higher levels make the pattern denser, so print it larger. Keep the white border (the quiet zone, four modules wide) when you crop or place the image, because scanners need it to find the code. Download the SVG for print layouts: it stays sharp at any size. ## Tips - Put a guest network on the card rather than your main network, so visitors never see the password you use for your own devices. - The password is stored in the code itself. Anyone who can photograph the card can join, and if you change the password the old card stops working. - WEP keys are either 5 or 13 characters, or 10 or 26 hex digits. WEP is easy to break, so switch the router to WPA2 or WPA3 if you can. faq: - q: Is my Wi-Fi password sent anywhere? a: No. The QR code is built by JavaScript in your browser. The network name and password are never uploaded, logged or saved, and they disappear when you close the tab. - q: Which phones can scan a Wi-Fi QR code? a: The built-in Camera app on iPhone (iOS 11 and later) recognises Wi-Fi codes and offers to join. On Android, the Camera app on most recent phones or Google Lens does the same, and Android 10 and later also has a scanner in the Wi-Fi settings (the QR icon next to Add network). - q: My network uses WPA3. Which security option should I choose? a: Choose WPA/WPA2/WPA3. The code's WPA type covers every WPA generation with a password, and the phone and router agree on the strongest one they both support when it joins. - q: Will the QR code still work if I change my Wi-Fi password? a: No. The code contains the password itself, not a link to it, so it cannot update. Make a new code after changing the password or the network name. - q: Can I add a logo in the middle? a: A logo covers part of the pattern, so only do it with error correction H, keep the logo under about a fifth of the code's width, and test the result on several phones before printing. ---
