PNG, SVG or print cards. category: Generators keywords: [wifi qr code generator, wifi qr code, qr code for wifi password, share wifi password, wifi qr code with logo, guest wifi qr code card, printable wifi qr code] howto: | ## How to make a Wi-Fi QR code 1. Type the **network name** (SSID) exactly as your phone lists it. Capitals, spaces and punctuation all matter. 2. Type the **password** and pick the **security** type. Almost every router uses WPA2 or WPA3, so leave it on WPA/WPA2/WPA3 unless your router settings say WEP or the network has no password. 3. Tick **Hidden network** only if the network does not appear in your phone's Wi-Fi list. 4. Scan the preview with your phone before you download or print it. The Camera app on iPhone and most Android phones offers to join the network. ## What is inside the code The QR code holds one line of text in the format first published by the ZXing barcode project: `WIFI:T:WPA;S:Home Network;P:secret pass;;`. The box under the preview shows the exact text for your network. | Field | Meaning | Values | |---|---|---| | `T:` | Security type | `WPA` (WPA, WPA2 and WPA3 Personal), `WEP`, or `nopass` | | `S:` | Network name | Up to 32 bytes; an accented letter takes 2, an emoji 4 | | `P:` | Password | Left out for open networks | | `H:` | Hidden network | `true` when the name is not broadcast | The characters `\`, `;`, `,`, `:` and `"` inside a name or password are escaped with a backslash, so `pa;ss` is written `pa\;ss`, and text is encoded as UTF-8. WPA passwords are 8 to 63 printable ASCII characters (or 64 hex digits); the tool warns about accented letters or emoji, which some devices refuse. The original ZXing Android scanner read a name made only of hex digits, such as `CAFE1234`, as hex bytes; **Quote a hex-only network name** wraps such a name in quotes if a scanner gets it wrong. ## Error correction, colours and logo | Level | Recovers about | Good for | |---|---|---| | L | 7% of the code | Clean screens | | M | 15% | Most uses (default) | | Q | 25% | Cards that get handled | | H | 30% | Worn prints, or a logo | A centre logo, either the built-in Wi-Fi symbol or your own image, hides part of the pattern, and error correction rebuilds it when scanning. Choosing a logo switches to level H, and the modules behind the logo are left blank. The tool estimates how much of the repair capacity the logo uses and warns when it is too large for the level you chose. Scanners need dark modules on a light background. The colour section shows the contrast ratio and warns below 4 : 1; black on white is 21 : 1. Light-on-dark codes are read by some phones but not all. Keep the white border (the quiet zone, four modules wide) when you place the image, and use the SVG for print layouts: it stays sharp at any size. ## Printing cards The card shows the heading, the network name and, if you like, the password next to the code. Choose 1, 2, 4, 6 or 8 cards per A4 or US Letter page; several cards are laid out with dashed cut lines, ready for a guest room or a front desk. Choose **Save as PDF** in the print dialog to keep a file. ## Tips - Put a guest network on the card rather than your main network. - The password is in the code itself, so anyone who can photograph the card can join, and the card stops working when you change the password. faq: - q: Is my Wi-Fi password sent anywhere? a: No. The QR code, the logo and the cards are made by JavaScript in your browser. The network name, password and any image you add are never uploaded, logged or saved, and they disappear when you close the tab. - q: Which phones can scan a Wi-Fi QR code? a: The built-in Camera app on iPhone (iOS 11 and later) recognises Wi-Fi codes and offers to join. On Android, the Camera app on most recent phones or Google Lens does the same, and Android 10 and later also has a scanner in the Wi-Fi settings (the QR icon next to Add network). - q: My network uses WPA3. Which security option should I choose? a: Choose WPA/WPA2/WPA3. The code's WPA type covers every WPA generation with a password, and the phone and router agree on the strongest one they both support when it joins. - q: Will a logo stop the code from scanning? a: Not if it is small enough for the error correction level. With a logo the tool switches to level H, clears the modules behind it and warns if the logo is too big. Always test the printed code with a couple of phones. - q: Will the QR code still work if I change my Wi-Fi password? a: No. The code contains the password itself, not a link to it, so it cannot update. Make a new code after changing the password or the network name. ---
