Press **Choose PDF files**, or drop one or more PDFs on the page. 2. Each file shows what protects it: a password to open it, restrictions such as no printing or copying, or nothing, and how it is encrypted. 3. Type the password and press **Unlock** or Enter. Every listed file that uses this password is unlocked. 4. Press **Download** beside a file, or **Download all** for a ZIP file. The files are read and saved again in your browser, never uploaded. ## Open password or permissions password? | Password | Also called | Needed to | Typed here, it | |---|---|---|---| | Open password | user password | open and read the file | removes the open password | | Permissions password | owner password | lift limits on printing, copying or changes | removes all protection | A PDF can have either, both, or one password for both. With the permissions password every restriction goes. With only the open password, that password goes but the restrictions stay: the copy is encrypted again with AES-256, opens without a password and keeps the same permissions, locked with a new random permissions password, so to lift them later start from the original file. A blank permissions password counts as known. Restrictions are enforced by PDF readers, not by the encryption itself, and Firefox's built-in viewer ignores them by default. Lift them only with the permissions password or the owner's consent. ## What cannot be unlocked - **A forgotten open password.** The contents are encrypted with a key made from it, and this page does not guess passwords. Ask the sender. - **Certificate security.** Such files open with the recipient's private key (a digital ID), not a password; this page does not open them. - **Rights management and DRM.** These files are opened with keys from the publisher's server, so they cannot be unlocked here. - **Files that encrypt only their attachments.** ## What the copy keeps The whole document is saved again as it was: pages, bookmarks, links, form fields, attachments, metadata and document properties. A digital signature no longer validates, because the file's bytes change, so keep the signed original. A copy that keeps its restrictions is stored less compactly, so a file with many links, bookmarks or form fields can come out several times larger. To work on the pages afterwards, use [split PDF](/split-pdf/), [merge PDF](/merge-pdf/) or [PDF to JPG](/pdf-to-jpg/). ## In Chrome or on a Mac Opening the PDF in Chrome with its password and printing it to **Save as PDF** also gives a copy without a password, but Chrome refuses to print a file that forbids printing, prints pages as pictures without selectable text when only low-quality printing is allowed, and the copy loses bookmarks, attachments and form fields.
