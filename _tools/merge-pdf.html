You can add more at any time. Every page appears as a thumbnail, numbered in the order it will have in the new file. - **Reorder files:** use the arrows in the file list, or **Sort by name**. Moving a file keeps all of its pages together. - **Reorder pages:** drag a thumbnail with the mouse, or use the arrow buttons under it, which also work with a keyboard and on touch screens. - **Rotate or remove pages:** use the buttons on each page, or tick several pages and use **Rotate** and **Remove** above the grid. **Undo** reverses the last change. - **Save:** **Merge into one PDF** saves every page in the order shown. **Save selected pages** saves only the ticked pages as a new PDF. ## Splitting a PDF To split instead of merging, choose how under **Split**: one PDF per page, a PDF for every few pages, or one PDF per original file with the pages you kept. The PDFs are saved together in a ZIP file. To pull out a few pages, tick them and press **Save selected pages**. ## What is kept Pages are copied as they are, not redrawn, so text stays selectable and searchable, pictures keep their quality and web links keep working. Each page keeps its size, so A4, Letter and landscape pages can sit in one document. Rotating sets the page's rotation value (the /Rotate entry of ISO 32000), which every PDF reader honours, so nothing is re-rendered and the file does not grow. Some things belong to the whole document rather than to a page, and are not carried over: bookmarks (the outline), links that jump to another page of the same file, fillable form fields, which keep their current look but may no longer be fillable, digital signatures, which are no longer valid once the file changes, and attachments. ## Password-protected PDFs Many PDFs are encrypted. A file that opens without a password but blocks editing or printing has only an owner password, and is unlocked and merged directly. A file that asks for a password to open shows a password box; enter the password you would use to open it. The merged PDF is saved without encryption, so protect it again if it needs protecting. RC4 and AES encryption of the PDF standard (40 to 256 bits) are supported; certificate-based encryption is not. ## Large files Thumbnails are drawn only when they scroll into view, and the new PDF is assembled in a background worker, so the page stays responsive with hundreds of pages. Everything is held in your device's memory, so very large jobs, over about 1 GB in total, are best done on a computer. faq: - q: Are my PDFs uploaded to a server? a: No. The files are read, previewed and merged by JavaScript in this page, on your own device. Nothing is sent over the network, so you can merge confidential documents safely. - q: Is there a limit on the number of files or pages? a: There is no fixed limit. Everything happens in your device's memory, so hundreds of files or thousands of pages work on a computer, while a phone may run out of memory sooner. - q: Why did the merged PDF lose its bookmarks or form fields? a: Bookmarks and form fields belong to the document, not to its pages, and this tool copies pages. The page content, web links and look are kept, but the outline is not, and form fields may no longer be fillable. Fill in forms before you merge them. - q: Can I merge a password-protected PDF? a: Yes. PDFs that only restrict editing or printing are unlocked automatically. For a PDF that needs a password to open, type that password in the box next to the file. The merged file is not password-protected. - q: Does merging reduce quality? a: No. Pages are copied without being re-rendered or recompressed, so text, vector graphics and images stay exactly as they were. ---
