Choose or drop one or more JPEG, PNG or WebP files. They are rewritten here in your browser, never uploaded. 2. Read the table for each photo: what was found, such as the GPS position, the time it was taken and the camera's serial number, and whether each item is kept or removed in the cleaned copy. 3. Press **Download** for each photo, or **Download all**. The cleaned files are named after the originals with `-clean` added. To check the result, open a cleaned file here again: it should report no metadata, apart from the colour profile and orientation tag if you kept them. ## Why the image quality stays exactly the same Metadata does not live inside the pixels. Each format stores it in separate blocks next to the compressed image, so the tool copies the image blocks byte for byte and leaves the metadata blocks out. Nothing is decoded or compressed again, so there is no quality loss. | Format | Removed | Kept | |---|---|---| | JPEG | EXIF and XMP (APP1), IPTC (APP13), comments, other APP blocks, data after the image | JFIF header, Adobe colour marker, ICC profile if chosen, image data | | PNG | tEXt, zTXt, iTXt, eXIf, tIME and unknown optional chunks | pixels, transparency, gamma and colour chunks, pixel density, animation, ICC if chosen | | WebP | EXIF, XMP and unknown chunks | image data, alpha, animation, ICC if chosen | {: .data .rexif-table} The Adobe APP14 marker is kept on purpose: it records how the colours were encoded, and some JPEGs decode with the wrong colours without it. Phone photos often carry a second image after the end of the main JPEG, such as a depth map, an HDR gain map or a motion photo clip. That data can have its own EXIF block, so it is removed too. ## The orientation tag A camera sensor has a fixed orientation. When you hold the camera upright, many devices store the pixels as the sensor saw them and set the EXIF Orientation tag (values 1 to 8 in the EXIF standard) so viewers rotate the picture when they show it. Delete that tag and the photo appears sideways. The options above handle this: - **Keep only that tag** writes a new EXIF block of a few dozen bytes that holds nothing but the orientation value. It stays lossless and reveals nothing about you. - **Remove it too** leaves no EXIF at all. Photos that relied on the tag will display rotated or mirrored. - **Rotate the pixels** re-encodes only the photos that need turning (JPEG and WebP at 92% quality), converting colours to sRGB. Photos without the tag are still cleaned losslessly. ## What photo metadata can reveal - **GPS position**, often accurate to a few metres, plus altitude and sometimes the direction the camera faced. - **Date and time** to the second, often with your time zone. - **Serial numbers** of the camera body and lens, which can link photos posted under different names to the same camera. - **An embedded thumbnail** that some editors do not update, so it can still show the uncropped original. - **Names and edit history** in XMP and IPTC fields: author, copyright, editing software, keywords and captions. Photos usually keep all of this when sent as a file in a messaging app, attached to an email or shared through a cloud storage link. Names such as `IMG_20230714_183205.jpg` also give away the date and time, so rename the file if that matters. faq: - q: Are my photos uploaded to a server? a: No. The files are read and rewritten entirely in your browser.
