That needs an alpha channel, which JPG does not have, so the tool saves PNG. The edge of the circle is anti-aliased: pixels on the rim are partly transparent, so the outline looks smooth on any background instead of jagged. If a site does not accept transparent images, choose **Colour, square image** as the background to fill the corners with a solid colour. ## How the crop is calculated At 100% zoom the shorter side of your image exactly spans the circle, so the circle is always filled. Dragging is limited so you cannot pull the image away from the circle's edge. Zooming out below 100% shrinks the whole picture inside the circle; the uncovered area stays transparent or takes the background colour, which is handy for logos. The crop is stored relative to the circle, not in screen pixels, so the downloaded file matches the preview at every output size. The editor shows a lighter copy of large photos to stay fast, but the download is drawn from the original pixels with high-quality resampling. If the circle covers fewer source pixels than the output size, the image has to be enlarged and will look soft; the tool tells you when that happens. ## Choosing a size Profile photo slots are small on screen but are shown at two or three times the resolution on phones and high-density displays, so bigger files stay sharper. | Output | Good for | |---|---| | 256 px | icons, forum and chat avatars | | 512 px | most profile pictures | | 1024 px | high-resolution profiles, small prints | | 2048 px | larger prints, further editing | {: .data .circ-table} A border is drawn inside the circle, so the file stays exactly the size you chose.
