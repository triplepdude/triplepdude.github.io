GIF pixels are either fully transparent or fully opaque. - **Quality.** JPG, WebP and AVIF discard detail the eye barely notices. 85 to 92% suits photos in JPG and WebP; lower settings give smaller files with visible blocks or smearing. PNG, GIF, TIFF and BMP ignore the setting. To meet a file-size limit instead, use the [image compressor](/compress-image/). - **Orientation.** A photo tagged as rotated is saved upright, so it looks the same everywhere; [Flip Image](/flip-image/) turns or mirrors pictures any other way. - **Metadata.** EXIF data (camera, date, GPS location) is removed by default. You can keep it for JPG, PNG and WebP, with or without the location. The rotation tag is then reset, because the pixels are already upright, and the embedded thumbnail is dropped. - **Colour.** Photos with a wide-gamut profile such as Display P3 are converted to sRGB, the colour space that web pages and most apps assume. - **Animation and pages.** Only the first frame of an animated GIF, PNG or WebP is kept, the first page of a multi-page TIFF, and the primary image of a HEIC file. The file list tells you when that happens. ## Making an ICO file An ICO file holds the same picture at several sizes, and Windows or the browser picks the one that fits. Each size is stored as a PNG, which every version of Windows since Vista and all current browsers read. For a website favicon, 16, 32 and 48 pixels are enough; Windows application icons also use a 256 pixel size. A picture that is not square is centred on a transparent square. Sizes larger than the original are enlarged and look soft; an SVG is drawn at the largest size instead, so it stays sharp. ## AVIF output Every current browser can open AVIF files, but most cannot create them from a web page, so the converter uses libavif with the libaom AV1 encoder, compiled to WebAssembly ([licenses](/assets/vendor/avif/README.txt)). A large photo can take several seconds; the limit is 50 megapixels. AVIF's quality scale is not JPG's: on a typical photo, 60 to 70% comes close to a JPG at 85 to 90% in roughly half the file size. faq: - q: Are my images uploaded to a server? a: No. Every image is decoded and re-encoded by your own browser.
