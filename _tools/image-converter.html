PNG and BMP ignore the setting. - **Lossless is not a repair.** Turning a JPG into a PNG keeps every pixel exactly, compression artefacts included, and the file usually grows. - **Orientation.** A phone photo tagged as rotated is saved upright, so it looks the same everywhere. - **Metadata.** EXIF data (camera, date, GPS location) is removed by default. The file list tells you when that happens. ## Making an ICO file An ICO file holds the same picture at several sizes, and Windows or the browser picks the one that fits. Each size is stored as a PNG, which every version of Windows since Vista and all current browsers read. For a website favicon, 16, 32 and 48 pixels are enough; Windows application icons also use a 256 pixel size. A picture that is not square is centred on a transparent square, and sizes larger than the original are enlarged, which looks soft, so start from an image at least 256 pixels wide for a crisp large icon. ## AVIF output Every current browser can open AVIF files, but a web page can only save AVIF when the browser includes an AVIF encoder for its canvas, and most do not.
