--- title: "Keyboard Tester: Test Every Key Online" description: Test every key on your keyboard online. Keys light up as you press them, with key codes, a rollover and ghosting counter, and key chatter detection. category: Device Tests keywords: [keyboard tester, keyboard test online, key tester, test keyboard keys, keyboard ghosting test, n-key rollover test, key chatter test] howto: | ## How to test your keyboard Press every key once; the keyboard picture is focused when the page loads. Keys turn solid while held and stay tinted after release, so a key that never lights up is faulty or swallowed before it reaches the browser. The counter tracks how much of the chosen layout you have covered. Pick **Tenkeyless** or **60%** to match a board without a number pad or function row. On the 60% drawing the top-left key counts whether it sends Esc or the backquote. Keys that are not on the drawing, such as media keys, F13 to F24 or the extra ISO key next to left Shift, appear under **Other keys**. On Macs and many laptops the top row sends brightness and media controls by default; hold Fn to test F1 to F12. While the keyboard picture is focused, the page blocks the default action of keys that would scroll or move you away: Space, the arrows, Page Up/Down, Home, End, Tab, Backspace, Alt, the Menu key and F1 to F12. Press **Esc twice** quickly, or click elsewhere, to stop capturing; focus moves to the **Capture keys** button and Tab carries on down the page. No web page can block system shortcuts such as Alt+Tab, Cmd+Tab or Ctrl+Alt+Del. ## What the numbers mean Each press fires a `keydown` event and each release a `keyup` event, as defined in the W3C UI Events specification. The panel shows these fields: | Field | Meaning | Example | |---|---|---| | `key` | The character or action produced, which depends on your layout and Shift | `a`, `A`, `Enter` | | `code` | The physical key position, named after the US QWERTY key in that spot | `KeyA`, `NumpadEnter` | | `keyCode` | Legacy numeric code, deprecated but still common in older scripts | `65`, `13` | | `location` | 0 standard, 1 left, 2 right, 3 numeric keypad | `ShiftRight` is 2 | | `repeat` | `true` for auto-repeat events while a key is held | | {: .data .kbt-gt} Because `code` describes position, a French AZERTY user who presses the key labelled A sees `code` = `KeyQ` and `key` = `a`. The drawing is lit by `code`, so it matches physical position whatever the printed legends say. Legacy `keyCode` values also differ between browsers for a few punctuation keys: Firefox reports 59 for the semicolon key, 61 for equals and 173 for minus, while Chrome and Safari report 186, 187 and 189. ## Rollover and ghosting **Max held at once** records the largest number of keys the browser saw down at the same moment, modifiers included. Hold keys together, for example A S D F J K L and semicolon, and check that each is listed under **Held now**. A keyboard with a basic matrix may drop the third or fourth key in some combinations (blocking), or report a key you did not press (ghosting). A USB keyboard that sends the standard 8-byte boot report can list at most six non-modifier keys plus the eight modifiers, so such boards stop at six letters, while gaming boards advertising n-key rollover should go higher. ## Key chatter A worn or dirty mechanical switch can bounce and register one press as two. The tester flags a **possible chatter** whenever a key goes down again within the chosen threshold (50 ms by default) of being released, which is faster than people normally repeat a key. The log's **Timing** column shows how long each key was held and the gap before its next press. If a switch chatters often, cleaning it with compressed air sometimes helps; otherwise the switch needs replacing. QMK and similar firmware also let you raise the debounce time. faq: - q: Is anything I type sent to a server? a: No. Key events are handled by JavaScript in this page and are kept only in memory while the tab is open. Nothing is uploaded, logged or stored, and the Reset button or closing the tab clears everything. - q: Why does a key not light up even though it works elsewhere? a: Some keys never reach web pages. The Fn key is handled by the keyboard or the operating system and sends no event, and shortcuts such as Alt+Tab or Cmd+Tab are taken by the operating system. The Windows key does reach the page, but the Start menu then takes focus. On Windows the Print Screen key only sends a key release, which the tester still counts. - q: Can I test my phone's on-screen keyboard? a: No. Touch keyboards on phones and tablets do not send physical key codes to web pages. A Bluetooth or USB keyboard connected to a phone or tablet does work; scroll the keyboard picture sideways on a narrow screen. - q: How many keys should the rollover counter reach? a: It depends on the keyboard. Boards that send the standard USB boot report stop at six non-modifier keys plus modifiers, n-key rollover gaming keyboards can show 10 or more, and many laptop and budget membrane keyboards block at 2 or 3 keys in some combinations. If a key you are holding is missing from Held now, the keyboard is blocking it. ---
