--- title: "Keyboard Tester: Test Every Key Online" description: Test every key on your keyboard online, in ANSI, ISO, TKL, 75%, 60% and Mac layouts, with key codes, a rollover test and key chatter detection. category: Device Tests keywords: [keyboard tester, keyboard test online, key tester, test keyboard keys, keyboard ghosting test, n-key rollover test, key chatter test] howto: | ## How to test your keyboard Pick your keyboard's size and layout, click the picture (or Tab to it and press Enter or Space), then press every key once. Keys turn solid while held and keep a tick after release, so a key that never lights up is faulty or swallowed before it reaches the browser. Keys that are not drawn, such as media keys or F13 to F24, appear under **Other keys**. On Macs and many laptops the top row sends brightness and media controls; hold Fn to test F1 to F12. The Fn key itself never reaches a web page, so it is drawn dashed and not counted. While capturing, the page blocks keys that would scroll or leave the page, such as Space, the arrows, Tab, Backspace and F1 to F12, and browser shortcuts such as Ctrl+S or Ctrl+P. Press **Esc twice in a row**, or click elsewhere, to stop. No page can block system shortcuts such as Alt+Tab, Cmd+Tab or Ctrl+Alt+Del, or a few browser ones such as Ctrl+W. ## Layouts | Layout | Keys | What differs | |---|---|---| | ANSI (US) | 104 | Wide Enter, long left Shift | | ISO (UK, German) | 105 | Tall Enter, extra key next to left Shift | | Tenkeyless | 87 or 88 | No number pad | | 75% | 83 or 84 | Function row and one nav column packed tight | | 60% | 61 or 62 | No function row, arrows or nav keys | | Apple laptop | 76 or 77 | Half-height function row and arrows | {: .data .kbt-gt} Compact boards vary between brands, so a key in a different spot on yours shows up under Other keys. The drawing is lit by `code`, the physical key position named after the US key in that spot, so the legend choice only changes the printed labels: on a German board the key labelled Z sends `KeyY`, and a 60% board's top-left key counts whether it sends Esc or the backquote. ## What the numbers mean Each press fires a `keydown` event and each release a `keyup` event, as defined in the W3C UI Events specification. `key` is the character or action produced (`a`, `A`, `Enter`), which depends on layout and Shift; `code` is the physical key (`KeyA`, `NumpadEnter`); `keyCode` is the deprecated legacy number (65, 13); `location` is 0 for standard keys, 1 left, 2 right and 3 numeric keypad; `repeat` is true for auto-repeat while a key is held. Legacy `keyCode` values differ between browsers for a few punctuation keys: Firefox reports 59 for semicolon, 61 for equals and 173 for minus, where Chrome and Safari report 186, 187 and 189. ## Rollover and ghosting Choose a combination under **Rollover test** and hold all its keys at once. Each key lights when the keyboard reports it, and the result keeps the most that registered together. A keyboard with a basic matrix may drop the third or fourth key (blocking) or report a key you did not press (ghosting), which shows as an extra held key. A USB keyboard that sends the standard 8-byte boot report stops at six non-modifier keys plus modifiers, while n-key rollover boards should pass every combination. Test the combinations you actually use, such as W, A, S and D with Shift and Space for games. ## Key chatter A worn or dirty switch can bounce and register one press as two. The tester flags **possible chatter** when a key goes down again within the chosen threshold (50 ms by default) of being released, faster than people repeat a key on purpose, and lists each such key with its count and shortest gap. The log's **Timing** column shows how long each key was held and the gap before its next press. Compressed air sometimes cures a chattering switch; otherwise it needs replacing, and QMK and similar firmware let you raise the debounce time. faq: - q: Is anything I type sent to a server? a: No. Key events are handled by JavaScript in this page and are kept only in memory while the tab is open. Nothing is uploaded, logged or stored, and the Reset button or closing the tab clears everything. - q: Why does a key not light up even though it works elsewhere? a: Some keys never reach web pages. The Fn key is handled by the keyboard or the operating system and sends no event, and shortcuts such as Alt+Tab or Cmd+Tab are taken by the operating system. The Windows key does reach the page, but the Start menu then takes focus. On Windows the Print Screen key only sends a key release, which the tester still counts. - q: Can I test my phone's on-screen keyboard? a: No. Touch keyboards on phones and tablets do not send physical key codes to web pages. A Bluetooth or USB keyboard connected to a phone or tablet does work; scroll the keyboard picture sideways on a narrow screen. - q: How many keys should the rollover test reach? a: It depends on the keyboard. Boards that send the standard USB boot report stop at six non-modifier keys plus modifiers, n-key rollover gaming keyboards pass every combination, and many laptop and budget membrane keyboards block at 2 or 3 keys in some combinations. If a key you are holding stays dark, the keyboard is blocking it. ---
