The preview shows the document with the font, size and spacing you pick. Press **Download .docx** for a Word file, or **Copy as rich text** and paste into Google Docs, Word, Outlook or any editor that accepts formatted text. ## What you get in Word The file is built as real Word structure, not as pasted web text, so it stays easy to edit: | Markdown | In the .docx | |---|---| | `#` to `######` headings | Heading 1 to Heading 6 styles, listed in the Navigation pane | | `-` and `1.` lists, nested | Word bullets and numbering; each list restarts at its own first number | | `- [ ]` and `- [x]` | Checkboxes you can tick in Word | | Tables | Word tables with a repeating header row and the column alignment | | Fenced code | A shaded monospace block, syntax-coloured if you choose | | `[^1]` footnotes | Real Word footnotes at the foot of the page | | `$…$` and `\[…\]` math | Word equations you can edit with the equation editor | | Links and `#heading` links | Clickable hyperlinks and jumps to bookmarks | Bold, italic, strikethrough, inline code, block quotes, horizontal rules, `\newpage` page breaks, and HTML such as ``, ``, ``, `` and `
` are kept too. The document uses the styles Normal, Heading 1–6, Quote, Code Block and Table Grid, so changing a style in Word restyles every paragraph that uses it. ## Equations from ChatGPT and other assistants Formulas are read with KaTeX, which turns LaTeX into MathML, and the MathML is rewritten as Office Math (OMML), the format of Word's own equations. Fractions, roots, powers and indices, sums and integrals with limits, accents, brackets that grow with their contents, and matrices all become editable equations. The `\( … \)` and `\[ … \]` delimiters used by ChatGPT work as well as dollar signs. Prices such as "$5 and $10" stay text, because a closing dollar sign may not follow a space. ## Pictures Pictures embedded as `data:` addresses go straight into the file. For pictures stored next to your `.md` file, open or drop the image files as well; they are matched by file name. PNG, JPEG and GIF are embedded as they are, and other formats, such as WebP or SVG, are converted to PNG. Phone photos stored sideways with an EXIF rotation tag are turned upright first, so they face the right way in every editor, whether or not it reads that tag. Pictures on other websites are not downloaded, so they appear as a link to the picture instead. ## Tips - Tick **Table of contents** for a Word table of contents that links to each heading. In Word, right-click it and choose **Update Field** to add page numbers. - Google Docs can also open the .docx directly: upload it to Drive and choose **Open with Google Docs**, which keeps footnotes, and usually equations, better than pasting. - Copy as rich text keeps formulas as their LaTeX source, since Google Docs and most editors cannot paste equations.
