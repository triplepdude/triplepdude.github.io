Runs in your browser, no upload. category: Image & PDF keywords: [compress image, compress image to 50kb, compress jpeg to 100kb, reduce image size in kb, image compressor, compress photo to 20kb, resize image to kb] howto: | ## How to compress an image to a specific size 1. Choose, drop or paste an image. JPG, PNG and WebP work, plus any other format your browser can open. 2. Pick the output: **JPG** works everywhere, **WebP** is usually smaller and keeps transparency. 3. Type the maximum size in KB, or tap a common limit. The tool finds the highest quality that fits. To set the quality yourself, switch to **A quality level**. 4. Drag across the preview to compare the original (left) with the compressed version (right). Tick **Actual size** to inspect detail, then press **Download**. ## How the target size is found Browsers encode JPG and WebP at a quality setting, shown here as 1 to 100%, but the resulting file size depends on the picture: a clear sky compresses far better than foliage or text. There is no formula from kilobytes to quality, so the tool searches. It first encodes at 30% quality. If that fits, it tries higher qualities, aiming each try from the sizes seen so far, and keeps the highest one up to 95% that is still under the limit. That takes a handful of trial encodes, which run in a background worker so the page stays responsive even with a 12-megapixel photo. If even 30% is too large, the pixel dimensions have to shrink. File size grows roughly with the number of pixels, so the tool scales both sides by about the square root of the overshoot, tries again, and tells you the new size. Below about 30%, JPG shows obvious blocky 8×8 artefacts, and a slightly smaller image at a sensible quality usually looks better than a full-size one covered in them. If a form demands exact pixel dimensions, tick **Keep the width and height**: the search then goes as low as 1% quality instead, and tells you if even that is too big. ## KB means 1,000 bytes here Some systems count 1 KB as 1,000 bytes and others as 1,024; Windows shows sizes in 1,024-byte units but labels them KB. This tool uses 1,000, the stricter reading, so a file made for a 50 KB limit is at most 50,000 bytes and also passes a checker that allows 51,200. The exact byte count is shown under the results. | Limit | 1 KB = 1,000 bytes | 1 KB = 1,024 bytes | |---|---|---| | 20 KB | 20,000 | 20,480 | | 50 KB | 50,000 | 51,200 | | 100 KB | 100,000 | 102,400 | | 1 MB | 1,000,000 | 1,048,576 | {: .data .cmpi-table} ## What else changes when an image is compressed - **Transparency:** JPG has no alpha channel, so transparent areas of a PNG or WebP are filled with white. Choose WebP to keep them. - **Metadata:** re-encoding drops EXIF data, including the GPS location. The rotation a phone recorded is applied to the pixels first, so the photo stays upright. - **Colour:** wide-gamut photos are converted to sRGB, the colour space most screens and websites assume. - **Animation:** only the first frame of an animated GIF or WebP is kept. If your original is already small, a re-encoded copy can come out larger. The tool warns you when that happens, and the original is then the better file to use. faq: - q: Is my image uploaded to a server? a: No. The image is decoded and re-encoded by your own browser with the Canvas API. It never leaves your device, and the page keeps working offline once loaded. - q: Why did the width and height change? a: The target could not be reached even at 30% quality, so the image was scaled down until it fits. To keep the original dimensions, tick Keep the width and height, which lowers the quality further instead. You can also raise the size limit or choose WebP, which is usually smaller at the same quality. - q: What quality setting should I use? a: For photos, 70 to 85% is hard to tell from the original and much smaller. Below about 40% blocky artefacts start to appear around edges and in smooth gradients. Use the compare slider to judge. - q: Can I compress a PNG and keep it as PNG? a: Not here. PNG is lossless, so it cannot be squeezed to a chosen size the way JPG and WebP can. Save as WebP to keep transparency at a fraction of the size. - q: Is the result exactly the size I typed? a: It is the largest quality step that stays at or under your limit, usually within a few percent of it.
