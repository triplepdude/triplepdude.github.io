That is what a lottery pick, a raffle or a random running order needs. Ask for as many numbers as the range holds and you get every number once, shuffled: 30 numbers from 1 to 30 puts a class of 30 in random order. A draw of 6 from 49 has 13,983,816 possible combinations, so one ticket matches all six about once in 14 million draws. No way of picking numbers changes those odds. Without the tick each number is drawn on its own, like rolling a dice again and again, so the same number can come up twice. ## Is it really random? | Property | `Math.random()` | This page | |---|---|---| | Generator | xorshift128+ in Chrome's V8 engine | `crypto.getRandomValues` | | Built for | Speed | Cryptography | | Predictable? | Yes, from a few earlier results | Not in practice | `Math.random()`, JavaScript's everyday generator, is built for speed. In Chrome it is a formula with 128 bits of internal state, and the V8 team describes it as not cryptographically secure: someone who sees a handful of its results can work out the state and every number that follows. This page never uses it. It asks the browser's cryptographically secure generator instead, which browsers seed from the operating system's store of unpredictable data. It is still an algorithm, so strictly its numbers are pseudo-random, but there is no known way to predict the next one. ## Every number equally likely The usual shortcut, dividing a random 32-bit number by the size of the range and keeping the remainder, favours the low numbers slightly, because 2³² is not a multiple of most range sizes. This page takes only as many random bits as the range needs and draws again whenever the result falls outside the range, so every number has exactly the same chance. Decimals are drawn the same way from every value with the chosen number of places: 0 to 1 with 2 places is one of the 101 values 0.00, 0.01, up to 1.00. Ranges are handled as exact whole numbers up to 1,000 digits long, so a 50-digit minimum and maximum work, without the rounding that ordinary JavaScript numbers show above 9,007,199,254,740,992 (2⁵³).
