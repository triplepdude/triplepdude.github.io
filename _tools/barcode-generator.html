A made-up EAN or UPC scans correctly but may collide with someone else's product. ## How the check digit works EAN, UPC and ITF-14 all use the GS1 modulo-10 check. Starting from the rightmost digit before the check digit, multiply the digits alternately by 3 and 1, add them up, and take the amount needed to reach the next multiple of 10. For `400638133393` the weighted sum is 89, so the check digit is 1 and the full EAN-13 is `4006381333931`. Code 128 always carries a hidden modulo-103 checksum, added automatically. Code 39 has an optional modulo-43 check character; only turn it on if the system reading the labels expects one, because it becomes part of the data. ## How the encoding works Every bar and space is a whole number of *modules*, the narrowest width in the symbol. An EAN-13 is 95 modules wide: start guard `101`, six digits of 7 modules each, a centre guard `01010`, six more digits and an end guard. The first digit is not drawn as bars at all; it sets which of two patterns (odd or even parity) each of the next six digits uses. Code 128 has three code sets: A (capitals and control characters), B (upper and lower case) and C (pairs of digits). The generator picks the mix of code sets that gives the fewest symbols, packing runs of digits two per symbol. ## Printing tips - Keep the white margins (quiet zones), which the generator adds for you. Code 128, Code 39 and ITF-14 need at least 10 modules of clear space on each side. EAN-13 needs 11 on the left and 7 on the right, UPC-A 9 on each side and EAN-8 7 on each side. - Dark bars on a light background scan best. Red bars are invisible to many laser scanners, which use red light. - Do not stretch the image sideways in a layout program.
