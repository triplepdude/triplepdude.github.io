{%- comment -%} The image converter: drop zone, options, file list and script. It is the whole body of /image-converter/ and of each page for one conversion (WebP to PNG, PNG to JPG and so on). A page includes it once, after its front matter: {% raw %}{% include image-converter-tool.html format="png" hint="WebP files, as many as you like. Nothing is uploaded." %}{% endraw %} Every parameter is optional. With none, the page is exactly the hub converter. Text values are plain text (no HTML or Markdown). Put each value in double quotes, or in single quotes when the text contains a double quote. format Output format selected when the page opens: jpeg (or jpg), png, webp, avif, gif, tiff (or tif), bmp or ico. Default jpeg; an unknown value also gives jpeg. Options that do not apply to it start hidden and its note is in the HTML, so nothing moves when the script runs. The visitor can still pick any other format. With avif, AVIF output counts as possible until the browser check says otherwise, so no "cannot save" note flashes up first. hint The small line in the drop zone, under "or drop them here". Default "PNG, JPG, WebP, AVIF, GIF, BMP, ICO, TIFF, HEIC or SVG, as many as you like. Nothing is uploaded." Every input format is still accepted, whatever the hint names. quality Starting quality for JPG, WebP and AVIF output, a whole number of percent from 10 to 100 (not 0 to 1). Default 90. Values outside the range are clamped to it. background Colour that fills transparent areas in JPG and BMP output, #rrggbb or #rgb. Default #ffffff (white); an invalid value also gives white. File messages call #ffffff "white" and #000000 "black", other colours by their code. metadata EXIF data (camera, date, location) in JPG, PNG and WebP output: strip (remove all), nogps (keep, without location) or keep (keep all). Default strip; an unknown value leaves the first option, strip, selected. note Sentences added to the note under the options while the starting format is selected (say, when to keep PNG instead), and with webp_mode, while the starting mode is too. They follow the format's own note. Default none. animated_note Sentences added after "Animated image: only the first frame was converted." in the message of each animated input (GIF, APNG, WebP or AVIF), such as what keeps every frame. Default none. webp_mode lossless or lossy: shows a Lossless or Lossy switch while WebP is the chosen output, starting on this one. Lossless keeps every pixel and hides the quality slider; lossy uses it. Alpha is exact in both. Default none: no switch, and WebP is lossy at the quality, as on the hub. profile keep: a JPG, PNG or WebP with an RGB colour profile other than sRGB (iPhone Display P3, Adobe RGB) keeps its colours and its profile in JPG, PNG and WebP output (TTImage's keepProfile); other formats get sRGB, and each file's message says which happened. CMYK JPGs always become sRGB (and say so). Default none: every profile is converted to sRGB. presets Longest sides in pixels, separated by spaces (say "1280 1920 2560"), added to the Size menu as "Longest side 1920 px". Whole numbers from 16 to 20000; others are left out. Default none. compare true: each file that is not smaller than its original is flagged ("Larger than the original: keep the JPG"), the summary adds the total size before and after, and a box by the ZIP button leaves such files out of the ZIP. Default none: sizes per file only, as on the hub. WebP output, on every page: encoded by libwebp in a worker (TTImage's { wasm: true }), loaded on the first WebP save. A picture over WebP's 16,383 pixels a side, or over TTImage.webpLimits() (lower on phones), is scaled down to fit, with a note. A browser that can encode WebP neither way gets a per-file error, never a JPG in its place. The element ids (imc-...) are fixed, so a page holds one converter. The starting note (imc_note_init below) repeats the notes of syncControls() in the script: change both together.
