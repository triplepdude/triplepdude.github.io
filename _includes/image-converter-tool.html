{%- comment -%} The image converter: drop zone, options, file list and script. It is the whole body of /image-converter/ and of each page for one conversion (WebP to PNG, PNG to JPG and so on). A page includes it once, after its front matter: {% raw %}{% include image-converter-tool.html format="png" hint="WebP files, as many as you like. Nothing is uploaded." %}{% endraw %} Every parameter is optional. With none, the page is exactly the hub converter. Text values are plain text (no HTML or Markdown). Put each value in double quotes, or in single quotes when the text contains a double quote. format Output format selected when the page opens: jpeg (or jpg), png, webp, avif, gif, tiff (or tif), bmp or ico. Default jpeg; an unknown value also gives jpeg. Options that do not apply to it start hidden and its note is in the HTML, so nothing moves when the script runs. The visitor can still pick any other format. With avif, AVIF output counts as possible until the browser check says otherwise, so no "cannot save" note flashes up first. hint The small line in the drop zone, under "or drop them here". Default "PNG, JPG, WebP, AVIF, GIF, BMP, ICO, TIFF, HEIC or SVG, as many as you like. Nothing is uploaded." Every input format is still accepted, whatever the hint names. quality Starting quality for JPG, WebP and AVIF output, a whole number of percent from 10 to 100 (not 0 to 1). Default 90. Values outside the range are clamped to it. background Colour that fills transparent areas in JPG and BMP output, #rrggbb or #rgb. Default #ffffff (white); an invalid value also gives white. File messages call #ffffff "white" and #000000 "black", other colours by their code. metadata EXIF data (camera, date, location) in JPG, PNG and WebP output: strip (remove all), nogps (keep, without location) or keep (keep all). Default strip; an unknown value leaves the first option, strip, selected. note Sentences added to the note under the options while the starting format is selected (say, when to keep PNG instead). They follow the format's own note. Default none. animated_note Sentences added after "Animated image: only the first frame was converted." in the message of each animated input (GIF, APNG, WebP or AVIF), such as what keeps every frame. Default none. The element ids (imc-...) are fixed, so a page holds one converter. The starting note (imc_note_init below) repeats the notes of syncControls() in the script: change both together.
